## 项目背景

数据集聚焦于具有较强消费能力和健康管理意识的中高端体检人群，覆盖全国 340 个以上城市，样本以城市白领、企业管理层及高收入自由职业者为主，其中个人付费体检比例约占三分之一。

本项目围绕数据集公开的四类核心维度展开分析：

| 维度 | 内容 |
| --- | --- |
| 健康指标分布 | BMI、血压、血糖、血脂等核心指标的均值、中位数及异常检出率 |
| 分层对比 | 按年龄段（25-35 / 36-45 / 46-55 / 56+）、性别、城市线级（一线 / 新一线 / 二线 / 三四线）细粒度统计 |
| 异常排名 | 检出率最高的 TOP 20 健康问题及其与全国平均水平的偏差值 |
| 行为标签 | 主动筛查型 / 基础保障型 / 被动履约型，基于体检频次与加项偏好构建 |

## 关键结论

### 1. 代谢负荷高于全国平均水平

| 指标 | 本人群 | 全国参考 | 偏差 |
| --- | --- | --- | --- |
| 超重或肥胖 | 55.5% | 50.7% | **+4.8pp** |
| 血脂异常 | 42.6% | 40.4% | +2.2pp |
| 脂肪肝 | 38.2% | 29.6% | +8.6pp |
| 尿酸偏高 | 22.1% | 13.3% | +8.8pp |

### 2. 筛查强度推高检出率（"检出率 ≠ 患病率"）

甲状腺结节 36.9%（+14.9pp）、肺结节 19.0%（+11.0pp）显著高于全国。高检出率的背后是高分辨率超声与低剂量胸部 CT 在该人群中的高渗透率——这是**筛查强度效应**，而非单纯的患病率差异，解读时需谨慎。

### 3. 感染类与血压血糖指标低于全国

幽门螺杆菌阳性 26.1%（−13.9pp）、高血压 19.2%（−8.3pp）、空腹血糖偏高 10.8%（−1.6pp），与人群年龄结构偏年轻、健康干预前置有关。

### 4. 主动筛查型贡献主要客单价

| 行为标签 | 占比 | 体检频次 | 平均加项 | 次均消费 | 个人自费占比 |
| --- | --- | --- | --- | --- | --- |
| 主动筛查型 | 32.8% | 1.70 次/年 | 4.1 项 | **3,898 元** | 54.4% |
| 基础保障型 | 49.3% | 1.15 次/年 | 1.9 项 | 1,557 元 | 24.1% |
| 被动履约型 | 17.9% | 0.85 次/年 | 0.7 项 | 604 元 | 17.6% |

主动筛查型客单价是被动履约型的 **6.5 倍**，是高端健康服务与高端医疗险的核心付费客群。

## 分析链路

1. **设计数据字典**：依据数据集公开的四类维度，设计 40+ 字段的个体级数据结构
2. **设定人群结构与相关性参数**：年龄段 / 性别 / 城市线级 / 职业 / 付费方式的分布与交叉影响
3. **生成个体级记录**：含生理指标、21 项异常标记、体检频次、加项选择、消费金额、行为标签
4. **分层聚合统计**：计算检出率、均值 / 中位数 / 分位数，以及与全国平均水平的偏差
5. **可视化叙事**：输出结构化统计结果（JSON）驱动前端图表，形成 8 章节的分析页面

## 快速开始

```bash
# 1. 生成模拟数据并计算分层统计（产出 CSV + dashboard_data.json）
python generate_data.py

# 2. 将统计结果与 ECharts 注入模板，产出单文件页面 index.html
python build.py

# 3. 直接双击打开 index.html（内联了 ECharts，无需联网、无需服务器）
```

可选：运行时冒烟测试（`node smoke_test.js`），校验 14 个图表配置与 DOM 输出无异常值。

## 指标判定口径

| 指标 | 判定标准 |
| --- | --- |
| 超重或肥胖 | BMI ≥ 24 kg/m² |
| 高血压 | 收缩压 ≥ 140 mmHg 或舒张压 ≥ 90 mmHg |
| 血压偏高 | 收缩压 ≥ 130 mmHg 或舒张压 ≥ 85 mmHg |
| 空腹血糖偏高 | 空腹血糖 ≥ 6.1 mmol/L |
| 血脂异常 | TC ≥ 5.2 或 TG ≥ 1.7 或 LDL-C ≥ 3.4 或 HDL-C < 1.0 mmol/L |
| 尿酸偏高 | 男性 > 420 μmol/L，女性 > 360 μmol/L |
